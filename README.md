# NCS · 한 걸음

휴대폰, 태블릿, PC에서 사용하는 HTML·CSS·JavaScript 학습 퀴즈입니다.

홈페이지: https://EnabledDRS.github.io/NCS/

## 문제 구성

| 과목 | 문제 수 |
| --- | ---: |
| 의사소통능력 | 160 |
| 수리능력 | 90 |
| 문제해결능력 | 130 |
| 조직이해능력 | 80 |
| 기술능력 | 60 |
| 전체 | 520 |

사용자가 제공한 5개 NCS PDF의 문제·보기·표·그림·수식을 원본 이미지로 보존했습니다. 공통 지문은 연결된 모든 문제에 표시합니다. 원본 난이도와 평가시간을 사용합니다.

## 사용 방법

1. 한 과목 또는 여러 과목을 선택합니다.
2. 5·10·20·30문제, 전체, 또는 원하는 문제 수를 직접 입력합니다.
3. 난이도, 전체/미풀이/오답, 랜덤/번호순을 고릅니다.
4. 원본 지시에 맞춰 보기 버튼을 선택하고 **채점하기**를 누릅니다. 모든 문제에서 여러 버튼을 선택할 수 있으며, 정답 집합과 정확히 일치해야 정답입니다.
5. 정답과 원본 해설을 확인합니다. 이미지 클릭으로 확대할 수 있습니다.

학습 중단 후 이어 풀기, 문제별 이동, 중간 종료, 오답 재학습을 지원합니다. 미풀이 문제는 오답에 포함하지 않습니다.

## 기록 저장

**기기 연결**에서 영문·숫자 8자리 코드를 정하고, 다른 기기에서도 같은 코드를 입력하면 문제별 학습 기록과 진행 중인 세트를 자동으로 공유합니다. 구글 로그인은 필요 없습니다. 대소문자는 구분하지 않습니다. 새 코드는 확인 후 생성하며, 처음 연결할 때 기기에 있던 기존 기록도 합칩니다.

기록 저장 서버는 Sites의 D1을 사용합니다. 코드는 브라우저에서 PBKDF2로 변환하고, 서버는 변환값을 다시 해시한 공간 식별자만 저장합니다. 원래 코드는 서버나 GitHub 소스에 보관하지 않습니다. 따라서 코드를 잊으면 온라인 기록을 찾을 수 없습니다. 같은 코드를 아는 사람은 같은 기록을 읽고 변경할 수 있습니다.

채점 및 문제 이동·답안 선택을 자동 저장하고, 다른 기기에서는 접속·화면 복귀·20초 간격으로 최신 기록을 확인합니다. 기록은 문제별 최근 응답 시각으로 합쳐 오래된 기기의 기록이 최신 답안을 덮어쓰지 않도록 합니다. 진행 중인 세트도 최근 변경을 공유합니다. 여러 기기에서 동시에 다른 세트를 풀면 가장 최근에 변경한 세트가 이어 풀기 대상이 됩니다.

각 기기에도 기록을 보관하므로 네트워크 연결이 끊겨도 학습을 계속할 수 있고, 연결이 돌아오면 다시 저장합니다. **기록 저장 / 기록 불러오기**는 별도 파일 백업입니다. 내보낸 파일에는 현재 세션도 포함되지만, 가져오기는 문제별 학습 기록만 합칩니다. 브라우저 데이터 삭제 또는 시크릿 모드 종료 시 아직 온라인에 저장하지 못한 기록은 사라질 수 있습니다.

이미지의 페이지 이어짐은 한 장으로 연결하고 같은 열 너비를 유지하여 짧은 문장이 과하게 확대되지 않게 했습니다. 페이지 번호·하단 선·정답표가 해설 조각에 섞이는 부분도 제거했습니다.

## 원본 확인 사항

- 기술능력 30번: 원본 정답표는 ④, 상세 해설은 ①입니다. 상세 해설에 맞춰 **①**로 채점하며, 채점 후 화면에 불일치를 표시합니다.
- 기술능력 55번: 상세 해설 문항 번호가 **15번**으로 오기되어 있습니다. 원본 정답표와 3R 관련 문제 내용을 대조하여 55번에 연결했으며, 해설 이미지는 그대로 보존합니다.
- 의사소통능력 64번: 문제 페이지에 정답과 해설이 함께 인쇄되어 있습니다. 문제 부분만 표시하고 정답·해설은 채점 이후에 표시합니다.
- 선택지에서 ㄱ·ㄴ 등의 조합을 고르는 문항도 원본 그대로입니다. 지문·보기 문구를 새로 만들거나 조합을 재구성하지 않았습니다.

## 배포

외부 프레임워크나 빌드 과정이 없는 정적 사이트입니다. GitHub Pages에서 `main` 브랜치의 루트(`/`)를 배포합니다. `.nojekyll`로 원본 정적 파일을 제공합니다.

서비스 워커는 기본 화면·문제 데이터와 이미 열어 본 이미지를 캐시합니다. 처음 보는 문제 이미지는 인터넷 연결이 필요합니다. 전체 문제를 한 번에 다운로드하지 않습니다.

원본 자료의 권리는 해당 권리자에게 있으며, 이 저장소는 개인 학습을 위해 구성했습니다.
